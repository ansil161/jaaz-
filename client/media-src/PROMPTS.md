# JAAZ Experience Centre — render pack

> GENERATED by `node scripts/prompts.mjs`. Do not edit by hand —
> the slot names below are read by the app, and the status column is
> read from the build manifest. Re-run after every batch lands.

## How to use this

1. Generate into the slot path shown, as PNG, at least 1376px wide.
2. Save to `media-src/jaz-home/<slot>.png` (reels: `.mp4`, and/or `.webm`).
3. Run `node scripts/build-media.mjs` — it writes the AVIF/WebP
   derivatives and updates the manifest, and the app picks the render
   up with no code change.
4. Re-run this script to refresh the queue.

**Generate the master renders first** — `master/exterior`, `theatre/base`,
`living/base` — and confirm them before spending quota on variants. Every
later image has to look like the same house as those three.

natural depth of field. No cuts inside a clip: each one is a single
continuous move, because a cut in a 10-second loop reads as a glitch.

Every reel also wants a poster still at `<slot>-poster` — one frame of
the same shot. The poster paints first and is what reduced-motion
visitors see permanently, so it is worth generating even for a clip you
have not filmed yet.
