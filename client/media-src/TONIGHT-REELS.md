**0/6 landed.**

## How to use this

1. Generate each prompt below in Google Flow or the Gemini app. **16:9, ~8s.**
2. Download the result and save it EXACTLY as the filename shown, into:
   `client/media-src/jaz-home/tonight/`
3. When some or all have landed: `node scripts/build-media.mjs`
4. Re-run this script to refresh the queue.

You do **not** need to make poster frames. Each night already falls back to a
rendered house plate until its clip exists, and to a verified photograph after
that — so the section stays correct with none, some or all six present, and
gets better as each one arrives. Drop them in one at a time if you like.

If a clip stalls on first load, its `moov` atom is at the end of the file —
`build-media.mjs` will tell you, and print the one-line ffmpeg fix.
