## How to land a clip

1. Generate in Google Flow / Veo using the prompt for that sequence.
2. Save it as `media-src/jaz-home/<slot>.mp4` — the slot is printed with
   each sequence below. The folders match, so `theatre/walkthrough` goes to
   `media-src/jaz-home/theatre/walkthrough.mp4`.
3. **Re-encode with a keyframe on every frame** (see below).
4. Run `npm run media`. The clip is copied to `public/media/`, the manifest
   updates, and the app switches from the placeholder to the film with no
   code change.
5. Re-run this script to refresh the queue.

## The encoding requirement (this one is not optional)

An ordinarily-encoded H.264 can only seek to its nearest keyframe, which
are typically two seconds apart. Scrubbing such a file advances in visible
blocks and looks broken — and the fault is invisible from the markup, so it
reads as a bug in the site rather than in the file.

Every frame must be a keyframe:

```bash
ffmpeg -i input.mp4 -an \
  -vf "scale=1920:-2,fps=30" \
  -c:v libx264 -profile:v high -crf 20 -g 1 -preset slow \
  -movflags +faststart theatre-walkthrough.mp4
```

`-g 1` is the keyframe interval. `-an` drops audio — nothing here is heard.
Expect roughly 4-6x the file size of a normal encode; that is the trade, and
it is why sequences are short and separate rather than one long film.

A **mobile cut** at `-vf scale=1080:-2` saved alongside as
`<slot>.mobile.mp4` keeps phones off the desktop file.

## Consistency

The single hardest requirement. Every clip must look filmed in the same
residence, so the paragraph below is stamped onto every prompt and should
not be paraphrased per shot. Generate `02 theatre/walkthrough` first and
approve it; every later sequence is matched to that one.

> Single-storey contemporary residence. Full-height glazing on the east elevation, slim blackened-steel frames, deep roof overhang, flat parapet roof. Wide-plank smoked oak throughout the interior. Honed basalt on the terrace, laid in the same direction as the oak. Warm off-white lime plaster, charcoal acoustic fabric, and walnut battens at 40mm centres. Blackened steel reveals. Concealed cove lighting at 2700K, no visible fittings. Landscape lighting from below. Warm, low, directional. Slow continuous dolly at 1.55m eye height. No cuts inside a sequence. Natural depth of field, no fisheye.

> No people. No brand marks or logos. No on-screen text. No visible cabling. Photoreal architectural cinematography, no CGI sheen.
